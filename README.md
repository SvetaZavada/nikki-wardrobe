# ✧ Nikki Wardrobe

Личный трекер одежды Infinity Nikki: 2–5 ★, 5 стилей, 30 лейблов, фильтры по слотам, матрица пробелов и экспорт JSON/CSV.

**Сайт:** https://svetazavada.github.io/nikki-wardrobe/

## ☁️ Подключение приватной Google Таблицы

Сайт размещён публично на GitHub Pages, но личные данные хранятся в закрытой Google Таблице. Запросы к Sheets API выполняются **в браузере от имени авторизованного Google-пользователя**, без сервера и без опубликованных секретов.

### Один раз в Google Cloud

1. Перейди в [Google Cloud Console](https://console.cloud.google.com/) и создай проект, например `Nikki Wardrobe`.
2. В **APIs & Services → Library** найди **Google Sheets API** и включи его.
3. В **Google Auth Platform / OAuth consent screen** настрой экран согласия: для личного обычного Google-аккаунта выбери **External**, название `Nikki Wardrobe`, укажи контактный адрес. Добавь себя в **Test users**, если приложение находится в режиме Testing.
4. В **Clients / Credentials → Create OAuth client ID** создай клиент типа **Web application**.
5. В **Authorized JavaScript origins** внеси **ровно** `https://svetazavada.github.io` (без пути `/nikki-wardrobe/`).
6. Скопируй **Client ID** (выглядит как `123456789-abc.apps.googleusercontent.com`). **Client secret нам не нужен**.
7. Открой сайт и вставь Client ID в раздел **Google Sheets**, нажми **Войти через Google**. Выбери аккаунт, в котором находится таблица.

Настройки согласия Google могут показывать предупреждение о непроверенном тестовом приложении. Проверяй имя проекта и запрошенные права; если не хочешь предоставлять доступ, отмени вход. Scope `https://www.googleapis.com/auth/spreadsheets` позволяет этому приложению читать и изменять Google Таблицы, доступные твоему Google-аккаунту — этот доступ шире одной таблицы. Код намеренно обращается только к таблице Nikki Wardrobe.

**Таблица:** https://docs.google.com/spreadsheets/d/19TZeLB2-ua_KeogitgFomATC3Yik1xbMPqakxeNE0xc/edit

**Вкладка:** `Wardrobe`, колонки `A:L` (последняя колонка содержит JSON предмета для сохранения всех лейблов).

### Как работает синхронизация

- **Войти через Google** — загружает коллекцию из Google Таблицы. Если локальные и облачные данные расходятся, сайт сначала запрашивает решение.
- **Обычное добавление/редактирование/удаление** — после подключения сохраняется в Google автоматически.
- **↓ Загрузить из Google** — получает актуальную облачную коллекцию.
- **↑ Записать локальное** — вручную заменяет облачную коллекцию локальной (нужно подтверждение).
- **Выйти** — отзывает текущий access token и оставляет локальную копию.
- **↓ JSON** — создаёт независимую резервную копию гардероба.

При обнаружении изменений на другом устройстве приложение **останавливает автоматическую запись**, чтобы не затереть чужие изменения. Перед повторной загрузкой экспортируй локальные изменения, если они тебе нужны. Это простой персональный трекер, а не полноценное совместное редактирование.

### Безопасность и ограничения

- OAuth **Client ID публичный** и может использоваться в браузере; **Client secret никогда не сохраняй в репозитории**.
- Access token хранится только в оперативной памяти вкладки, а Client ID — в `localStorage`.
- Сайт не отправляет инвентарь на GitHub; код сайта публичен, таблица остаётся приватной.
- Вход может потребоваться снова после перезагрузки сайта или истечения токена.
- Нужны интернет, доступ к Google и работающие cookies/pop-up авторизации.
- Google OAuth в режиме Testing может требовать повторного согласия через 7 дней; это ограничение тестового режима Google.
- Изменение содержимого таблицы вручную во время работы сайта требует повторной загрузки.
- Набор сочетаний 5×30 — теоретический, не все пары существуют в игре.

Если OAuth выдаёт `origin_mismatch`, проверь Authorized JavaScript origins: должен быть только origin `https://svetazavada.github.io`, без пути.

## Локальный режим

Без входа через Google гардероб продолжает храниться в `localStorage` браузера. Используй регулярный экспорт **JSON**. CSV экспортируется для просмотра в таблицах, импорт восстанавливается из JSON.
