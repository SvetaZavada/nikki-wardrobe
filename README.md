# ✧ Nikki Wardrobe

Личный трекер одежды для **Infinity Nikki**.

## Возможности
- Добавление, изменение и удаление вещей
- Звёздность 2–5 ★, пять стилей, 30 лейблов
- Матрица покрытия «лейбл × стиль» и фильтрация по слотам
- Поиск и фильтры коллекции
- Локальное сохранение и резервное копирование в JSON
- CSV-экспорт для просмотра в таблицах

## Публикация через GitHub Pages
1. Открой **Settings → Pages** репозитория.
2. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку `main` и каталог `/(root)`.
4. Нажми **Save**.
5. После успешной публикации сайт будет доступен по адресу `https://svetazavada.github.io/nikki-wardrobe/`.

## Данные и приватность
**На текущем этапе Google Sheets не подключён.** Сохранение работает через `localStorage` в браузере. Для резервного копирования используй кнопку **↓ JSON**. Содержимое твоей коллекции не записывается в GitHub.

Google Таблица подготовлена для следующего этапа. Приватная авторизованная синхронизация пока не реализована. Не публикуй в репозитории токены, секреты и личные данные.
